# 象棋大战象棋

一个原生 HTML/CSS/JavaScript 制作的 5×9 棋盘塔防游戏。无需安装依赖，也无需部署。

## 开始游戏

直接双击 `index.html` 即可。若浏览器限制本地文件，也可以在当前目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 操作

1. 进入关卡后，从已解锁棋子中选择最多 6 种上场。
2. 在战场左侧选择一个国象棋子，再点击棋盘空格部署。
3. 金色能量球出现时，点击它可获得 50 能量。
4. 选择棋子栏顶部的“铲子”，再点击误放的棋子即可移除；任务目标王棋不可铲除。
5. 击破盾山将、霜辙车、镇国大将或紫蛇时有50%概率掉落能量豆。能量豆1.5秒后会自动飞入未满的豆槽，也可提前点击拾取；之后先点右上角能量豆，再点我方棋子发动爆发技。
6. 每枚我方棋子都有独立的1–5阶成长路线，而且不再套用“散射—分裂—破甲—死亡遗技”模板：兵可过河升变，车能空档装填重弹，冰/焰车可净化或熔化冰面，毒车会制造孢子傀儡，骑士会残血回营，王系操纵能量和卡牌冷却，棱镜后轮换光色。成长之路演示与正式战斗共用机制。
6. 右上角可暂停游戏；任何敌军越过最左侧防线都会导致失败。

## 内容

- 六章故事模式，包含关前/关后对话与最终 Boss 紫蛇。
- 六波坚守、120秒无限计分、守护特殊王棋、重甲围城、冰封棋盘、镜铲乱阵六种常规挑战，以及完全自由编排的“自定义房间”。
- 自定义房间可以逐队设置敌军种类、1–100枚数量与指定出兵行，也可使用“随机行”平均分散到五路；最多12队、总计300枚敌军。我方可从全部棋子中选择最多6种，并为每种单独指定1–5阶。房间使用2000初始能量，布阵完成后由玩家手动放出敌军，配置会自动保存到本地。
- 主页面“成长之路”可选择全部22枚我方棋子，逐项预览1–5阶质变和能量豆大招；演示会在中间三路自动编排，不会进入正式关卡。
- 成长演示会创建一份隔离的真实战场状态，并直接调用正式战斗的 `activateEnergyBean`、`updatePlayers`、`updateAbilityEvents`、`updateProjectiles` 与 `renderEntities`。演示窗口内部放置原尺寸的正式 `.board`，保持正式战斗的格子、棋子、血条、弹体、伤害数字和特效尺寸不变，再对整个战场统一等比缩放；项目不再维护任何演示专用棋盘或动画。
- 所有模式均从75能量开始，只够先部署一枚王或兵。
- 兵、车、王、马、象、后六种基础棋，以及双车、冰车、焰车、毒车、盾兵、投矛兵、雷马、霜马、双象、冰象、焰象、毒象、金王、御盾王、双后、棱镜后等十六种衍生棋。
- 霜马与毒象随故事推进开放；双后、冰象、焰象、御盾王属于秘藏棋，必须分别完成同局部署两枚后、制造12次冰雕、熔化15格冰面、让盾兵累计承受6000伤害等特殊条件。编队和成长之路会显示实时进度，解锁状态写入本地存档。
- 双车连发两枚车弹；冰车减速；焰车造成持续燃烧；毒车造成长时间中毒。
- 盾兵减伤40%；投矛兵越盾投射；雷马连锁电击；双象同时攻击两条对角线；金王高效产能；后作为450能量的三线车弹炮台；棱镜后消耗550能量，每0.8秒穿透扫射相邻三路。
- 全部攻击棋采用“更低单发、更高频率”的节奏：兵、车、马、象及其衍生棋的单次伤害降低约30%–45%，攻击间隔同步缩短，画面中的攻击动作更加连续。
- “开始对战”扩展为六种玩法：六波坚守、120秒歼灭、守护王棋、重甲围城、冰封棋盘、镜铲乱阵。选择玩法后还可选择新兵、标准、精英、噩梦四档难度；难度会真实改变敌军生命、攻击、速度、每波数量与生成间隔。
- “百二十秒”现为纯计分模式：120秒内敌潮不断，玩家尽可能多地击杀敌军，时间到后直接以本局击杀数结算，不再要求固定80杀。
- 每场战斗在编队后必须选择一个战前增益：额外100初始能量、全军伤害+15%、攻击频率+20%、部署冷却-35%，或开局获得1枚能量豆。增益仅在本场有效。
- 新增三种趣味玩法：“万金重甲阵”提供5000初始能量，“无限巨人阵”提供无限能量，“能量豆狂欢”提供3000能量与3枚能量豆。三关均无部署冷却，进入战场后先自由布阵，点击“阵型完成·开始来敌”才会放出以盾山将、镇国大将为主的重甲敌潮。
- 三种趣味玩法点击开战后会一次性创建100名重甲敌军，按五路纵深队列同时压入；盾山将与镇国大将的基础移动速度均提升为原来的2倍。
- 新增“万蛇窟”趣味模式：可选择100–1000条紫蛇，完成布阵后所有棋子无视能量豆数量持续自动释放大招。持续射击型大招只播放一次开场演出，例如后会每1.5秒重新发射15发普通弹；施法棋子的所在格会亮起其专属颜色底光。蛇潮按所选总数结算并分批补入战场，以控制同屏实体数量。
- 我方棋子正常阵亡和敌军被击破时会播放完整的失衡、侧翻、倒地和淡出动画；被镇国大将砸死或被掘阵卒铲飞时继续使用各自更夸张的专属动画。
- 成长之路属于完全隔离的演示战场；即使演示敌军突破左侧或摧毁演示棋子，也只会自动重开小窗演示，绝不会打开正式战败页面。
- 成长之路的持续实战会根据演示棋子的定位混排敌军：车系面对铁车、玄士和镜戏丑，投矛兵与象会遭遇掘阵卒和八卦相，马系面对赤马与重甲敌军，后系则在三路展示兵、炮、马、车等混合目标。
- 我方棋子全部使用 HTML/CSS 几何结构自绘，不再依赖浏览器内置的 Unicode 国际象棋字形。
- 子弹根据飞行距离使用更慢的弹道，并增加方向旋转、发光脉冲和长拖尾；炮弹、电光和光束整体放大至原来的1.5倍。
- 能量豆最多储存3枚：盾山将与霜辙车掉1枚，镇国大将掉2枚，紫蛇掉3枚。
- 兵的大招挥剑裂地，前2格每枚敌棋受500伤害；车系大招在1.5秒内连发15发正常威力炮弹，双车连发30发。
- 冰车先冻结当行前方所有棋格，对当行敌军无视防御造成100伤害，再连发15枚冰弹；焰车连发15枚火弹；毒车滚出一枚对整行敌军造成1500伤害的巨型毒球。
- 盾兵获得2000护甲，投矛兵发动矛雨，马系发动冲锋或全场链雷，象系清扫对角线，王系大量产能，后系发动全场光束。
- 普通攻击动画也按武器重做：兵挥剑、盾兵盾击、投矛兵从手中抛出长矛、马留下跃击轨迹、象打出弧形波、王生成能量光环；只有车系使用炮弹。
- 初始只解锁兵、车、王，故事进度会逐章解锁新棋子，每局最多携带 6 种。
- 每种我方与敌方棋子均有独立配色、光环、弹道和技能动画；掘阵卒手持铲子，霜辙车驾驶冰车，镜戏丑身边环绕四面悬浮镜。
- 十二种敌军，包括掘阵卒、镜戏丑、盾山将和霜辙车等干扰型单位。
- 敌車每5秒随机换线；炮隔一子轰击；相周期召唤；大将无视血量碾碎接触的棋子。
- 掘阵卒免疫平射并能直接铲飞棋子；兵、马和象可以克制它。
- 镜戏丑周期展开镜幕，将远程伤害的75%反弹给攻击者。
- 盾山将死亡后留下6500生命盾碑，占格并截停平射。
- 霜辙车经过的棋格永久结冰，本局无法继续部署。
- 八卦迷阵从第2波起每波保证出现敌相，其他长局第5波也会固定出现敌相。
- 敌军生命整体提高：兵800、炮1100、马1300、车3200、士1800、相2800、大将32000、紫蛇65000。
- 敌军从右侧入场时，在整个棋子圆盘完全进入棋盘前处于无敌状态：不会被选为攻击目标，也不会受到直接、范围或持续伤害；大体型敌军按其实际显示尺寸计算。
- 紫蛇移动速度提高至原来的2倍；未持续受到攻击时每秒恢复100生命。
- 棋子熟练度与更长期的 1–5 阶成长；每种棋采用独立质变路线，例如双后会跨路议会，冰象会制造霜桥，焰象能焚阵，毒象可传染敌相援军，御盾王会构筑移动王城。
- 5阶的长期目标战力为1阶的约3–4倍，但每种棋保留独立机制：例如车的普通车弹有20%概率改为4连射，双车则依靠连续命中后的极速鼓点。不为所有5阶棋套用同一被动。
- 随故事进度解锁的敌军资料库。
- 游戏进度自动保存在浏览器本地存储中。
